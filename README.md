NFC Reader For Kentkart 🚌📱
NFC teknolojisi aracılığıyla Kentkart'tan (İzmir ve diğer şehirlerde kullanılan toplu taşıma kartları) veri okumak ve çıkarmak için tasarlanmış bir uygulama.

📖 Genel Bakış
NFC-Reader-For-Kentkart, Kentkart ulaşım sistemi tarafından kullanılan akıllı kartlarla (MIFARE Classic veya DESFire gibi) etkileşime girmeyi amaçlayan eğitim odaklı bir projedir. Kriptografik güvenliği atlamadan kartın Benzersiz Kimlik Numarasını (UID) okumak ve herkese açık olarak okunabilen sektörlerle etkileşim kurmak için NFC özelliklerinden yararlanır.

✨ Özellikler
NFC Etiket Algılama: NFC özellikli bir cihaza okutulduğunda Kentkart'ı anında algılar.

UID Çıkarma: Toplu taşıma kartının benzersiz onaltılık (hexadecimal) seri numarasını okur.

Hex/Veri Ayrıştırma: Ham baytları okunabilir formatlara dönüştürür.

Hafif ve Hızlı: Hızlı kart okuma için minimalist yapı.

🛠️ Teknoloji Yığını (Tech Stack)
(Bu bölümü kendi özel uygulamanıza göre güncellemekten çekinmeyin)

Diller: Dart / Java / Python / C#

Framework (Çerçeve): Flutter / Android SDK / .NET

Kütüphaneler: Platforma bağlı olarak (örneğin; Flutter için nfc_manager, yerel Android için android.nfc, Python için pyscard).

🚀 Başlangıç
Ön Koşullar
NFC özellikli bir mobil cihaz VEYA USB NFC Okuyucu (ör. ACR122U).

Uygun geliştirme ortamı (Android Studio, VS Code vb.).

Test için fiziksel bir Kentkart.
